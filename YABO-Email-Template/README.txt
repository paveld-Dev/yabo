QUICK START (3 STEPS TO SEND)
--------------------------------------------------------------------------------

STEP 1: CHOOSE YOUR HTML VERSION
  - Option A (Recommended for Email Service Providers like Mailchimp/Klaviyo):
    Use 'HTML/index.html'. Upload the images in 'Images/' to your CDN or ESP
    media gallery and update the image src attributes.
  - Option B (Instant Self-Contained):
    Use 'HTML/email-embedded.html'. All imagery is embedded directly as Base64
    data URIs—requires no external image hosting!

STEP 2: CUSTOMIZE CONTENT
  - Open the HTML file in any text or code editor (VS Code, Notepad, Sublime).
  - Search for 'mc:edit' tags to quickly find editable text blocks.
  - Replace placeholder URLs ('https://example.com/...') with your real links.

STEP 3: TEST & SEND
  - Send a test email to your inbox or preview in Litmus / Email on Acid.
  - Test across desktop and mobile to ensure your links and text are perfect.
