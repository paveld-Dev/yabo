1. Introduction & Template Overview

YABO is a handcrafted, editorial-grade HTML email newsletter template tailored for food and beverage establishments. It combines contemporary California lifestyle editorial sensibilities with Nordic minimalist restraint.

Engineered with a solid 600px table-based grid, Microsoft Outlook MSO conditional width locks, and fluid CSS media queries, YABO renders reliably across desktop, web, and mobile email clients while preserving rich typography and high-end visual pacing.

Key Architectural Highlights:
• 8 Modular, re-orderable content sections with Mailchimp mc:repeatable tags.
• 35 Unique mc:edit fields for zero-confusion visual editing.
• Bulletproof table buttons with solid background fallbacks.
• Outlook webfont protection ensuring graceful fallback to Georgia & Arial.
• Clean relative image paths for easy local inspection and straightforward CDN migration.

3. How to Edit Text

Open HTML/index.html in any text editor (such as VS Code, Sublime Text, or Notepad++). Every text region is indexed with a descriptive, unique mc:edit tag:

  • mc:edit="nav_1", nav_2", nav_3": Header navigation links.
  • mc:edit="hero_eyebrow", hero_title", hero_subtitle": Hero card heading and description.
  • mc:edit="philosophy_title", philosophy_body": Editorial story module text.
  • mc:edit="dish1_title" through dish4_title": Signature dishes titles and descriptions.
  • mc:edit="fav_heading", fav_sub", fav_desc": Chef's favourite highlight section.
  • mc:edit="dine_title", dine_desc", dine_hours": Dine-in section and opening hours.
  • mc:edit="deliv_title", deliv_body": Takeout & delivery banner text.
  • mc:edit="footer_address", footer_copyright": Footer address and legal text.

Simply replace the text inside the HTML tags while preserving the surrounding styling attributes.

5. How to Host Images Using HTTPS

Mandatory Sending Requirement:
Email clients (like Gmail, Outlook, Yahoo) cannot access files located on your computer (../Images/...). Before sending an actual broadcast or campaign, you must host your images on a public HTTPS web server or CDN and update the image URLs.

Step-by-Step Hosting Guide:

  1. Upload all files from the Images/ directory to your website server, AWS S3 bucket, Cloudinary, or your ESP's media library (e.g., Mailchimp Content Studio or Klaviyo Asset Manager).
  2. Obtain the public HTTPS URL for the images directory (for example: https://yourdomain.com/email-assets/).
  3. Open HTML/index.html in your code editor.
  4. Perform a global Find and Replace:
    • Find: ../Images/
    • Replace with: https://yourdomain.com/email-assets/
  5. Save the updated HTML file. Your template is now ready to broadcast!

7. How to Update Buttons & Links

Buttons are engineered using bulletproof table cells with explicit background colors, internal anchor padding, and MSO spacing attributes: 

<table border="0" cellspacing="0" cellpadding="0" role="presentation" align="center">
  <tr>
    <td align="center" bgcolor="#5D7A68" style="border-radius: 28px; background-color: #5D7A68;">
      <a href="https://yourdomain.com/menu" target="_blank" style="display: inline-block; padding: 14px 38px; font-family: 'Geist', sans-serif; font-size: 11.5px; font-weight: 700; color: #FFFFFF; text-decoration: none; border-radius: 28px; text-transform: uppercase; letter-spacing: 0.16em;">
        EXPLORE THE NEW MENU &#8594;
      </a>
    </td>
  </tr>
</table>

To update the destination link, replace https://yourdomain.com/menu with your URL. To change the button color, update both the bgcolor="..." attribute and the CSS background-color: ... style on the <td> element.

8. Instructions for Supported Email Platforms

A. Mailchimp Integration

  1. Log in to your Mailchimp account and navigate to Campaigns → Email Templates → Create Template.
  2. Select the Code Your Own tab and choose Import HTML or Paste in code.
  3. Paste the contents of HTML/index.html (with your hosted image URLs).
  4. Mailchimp will automatically recognize the 35 mc:edit blocks and 8 mc:repeatable sections, allowing visual in-browser editing and section re-ordering.
  5. Ensure the footer contains the merge tags: *|UNSUB|* (Unsubscribe) and *|UPDATE_PROFILE|* (Preferences).

B. Klaviyo, Campaign Monitor, SendGrid & Other ESPs

  1. Create a new custom HTML template in your platform.
  2. Paste the HTML code.
  3. Update the unsubscribe merge tag to match your platform's format:
    • Klaviyo: Replace *|UNSUB|* with {% unsubscribe %}
    • Campaign Monitor: Replace *|UNSUB|* with <unsubscribe>Unsubscribe</unsubscribe>
    • SendGrid: Replace *|UNSUB|* with {{{unsubscribe}}}

9. Responsive Behavior & Breakpoints

YABO utilizes a mobile-first fluid hybrid approach. The desktop layout is locked at 600px. When viewed on smaller viewports, the media query @media only screen and (max-width: 600px) triggers fluid responsive behavior:

  • 600px – 414px (Phablets / Large Phones): The outer canvas margins collapse to zero; the container becomes 100% fluid; fonts and padding scale proportionately.
  • 375px (Standard iPhone): Multi-column tables (such as the alternating signature dishes) convert to single-column vertical cards (.mobile-stack) with centered circular photography.
  • 320px (Compact Mobile): Button padding and headlines adapt to prevent horizontal overflow; secondary navigation items gracefully hide (.mobile-hide) to keep the header uncluttered.

10. Email-Client Compatibility Notes

The template has been engineered to comply with major email rendering engines:

A. Built-in Code-Level Compatibility Architecture

Rather than relying on unpredictable modern CSS, YABO is built with defensive HTML email architecture verified at the code level:

Client Engine Engineering Defense Implemented Fallback Behavior
Microsoft Outlook (Word Engine: 2016–2021, LTSC, Office 365) MSO conditional wrapper tables (<!--[if (gte mso 9)|(IE)]>) lock width to 600px. Multi-column zigzag rows use MSO table cells. Container width is constrained to 600px. Columns stay side-by-side.
Outlook Desktop Fonts MSO font defense CSS block in <head> targeting h1, h2, h3, em, span, p. Gracefully substitutes Georgia (for serif) and Arial (for sans) rather than defaulting to Times New Roman.
Gmail (Webmail & Mobile Apps) HTML file size kept at ~44 KB (well under Gmail's 102 KB clipping threshold). Embedded PNG icons used instead of SVGs. Email is never clipped. Icons render cleanly without broken image placeholders.
Apple Mail (iOS & macOS) WebKit rendering engine supports Google Web Fonts (Cormorant Garamond & Geist) and hover effects. Full high-fidelity editorial rendering with Retina graphics.
Yahoo! Mail & AOL Standard table structure with fluid hybrid media queries. Fluid container adaptation and bulletproof button rendering.

11. Known Limitations

  • Outlook Desktop Web Fonts: The Microsoft Word engine powering Windows Outlook does not load external web fonts. The template includes MSO defense rules that automatically substitute Georgia for serif headings and system sans-serif for body text, avoiding the notorious "Times New Roman" bug.
  • Base64 Data URIs: Major email clients (specifically Gmail and Outlook) block or strip Base64 embedded images. Always use HTML/index.html with hosted HTTPS image URLs for broadcast campaigns.
  • Background Video / CSS Grid: These modern web technologies are unsupported across email clients and are intentionally omitted in favor of universal table-based markup.

14. Troubleshooting Guide

Common Questions & Solutions:

Q: Images appear broken when I test sending the email.
A: Confirm that you have hosted your images on a public HTTPS server or CDN and replaced all instances of ../Images/ with your live HTTPS domain. Email clients cannot access local file paths.

Q: The template stretches too wide in Windows Outlook.
A: Ensure you have not deleted the <!--[if (gte mso 9)|(IE)]> conditional comments located around the main email container table. These tags lock the width to 600px in Microsoft Outlook.

Q: Mobile view is not showing responsive changes in Gmail.
A: Gmail clips email bodies exceeding 102 KB. Keep your final HTML file size below 102 KB (YABO's production HTML is ~39 KB, well below this limit). Also ensure your ESP does not strip <style> tags during campaign creation.
