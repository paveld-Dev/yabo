2. Modular Architecture (8 Modules)

Every section is tagged with data-module, mc:repeatable, and mc:edit tags for seamless integration with Mailchimp, Campaign Monitor, Klaviyo, or your custom email marketing platform:

Module Name Tag Identifier Description & Background
01. Minimal Brand Header data-module="brand-header" Crisp SVG logo + 3-link editorial navigation on clean white (#FFFFFF).
02. Hero Section data-module="hero-section" Full-width overhead flatlay banner + floating square editorial card on #DCE6DE.
03. Editorial Story Intro data-module="story-intro" Botanical glyph, editorial serif headline, and philosophy body on meadow cream #FAF8F5.
04. Signature Dishes data-module="signature-dishes" 4-dish alternating zigzag layout with circular photography on Sage Green #5D7A68.
05. Chef's Favourite data-module="chef-favourite" Gold star accents, large circular dish hero, price pill CTA on #FFFFFF.
06. Dine-in Sanctuary data-module="dine-in" Walk-in invitation with operating hours badge on warm stone #F5F3EF.
07. Takeout & Delivery data-module="delivery" Flush kraft bag packaging photo + spacious green block on #688574 with partner badges.
08. Minimalist Footer data-module="footer" Footer brand mark, secondary nav, social SVG icons, address, legal, and unsubscribe links.

3. How to Customize

A. Editing Text and Links

Open HTML/index.html in any code editor (VS Code, Sublime, Notepad++). Search for the mc:edit tags to quickly locate text elements:

  • hero_title: Update the main headline in Module 02.
  • dish1_title to dish4_title: Update dish names in Module 04.
  • deliv_title: Update the delivery banner headline in Module 07.
  • Replace https://example.com/... placeholder links with your actual URLs.

B. Uploading Images to a CDN

When sending via Mailchimp, Klaviyo, or SendGrid, upload the files in Images/ to your ESP's image manager or web CDN, then update the src="..." attributes: 

<!-- Before: Local relative path -->
<img src="../Images/hero.jpg" width="600" alt="YABO Spread" />

<!-- After: Your Hosted CDN URL -->
<img src="https://yourdomain.com/cdn/images/hero.jpg" width="600" alt="YABO Spread" />

Alternatively, if you want an email that works with zero external image hosting, use HTML/email-embedded.html where all images are base64 encoded.

C. Removing Unused Modules

Each module is contained inside a single <tr data-module="...">...</tr> block. To remove any module, simply delete or comment out the entire <tr> block.
